# Riviu

Review GitHub pull requests in a native Mac app, with AI review, guided tours and code navigation.

Needs a Mac with Apple silicon and macOS 27.

## Install

Paste this into Terminal:

```sh
curl -fsSL https://raw.githubusercontent.com/slavkobojanic/riviu/main/scripts/install.sh | bash
```

Or download `Riviu.dmg` from the [latest release](https://github.com/slavkobojanic/riviu/releases/latest) and drag
Riviu to Applications. Riviu updates itself after that.

## Build from source

Open `Riviu.xcodeproj` in Xcode 27 and run the Riviu scheme.
